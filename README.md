# Celyn Launcher

Celyn Launcher is a Windows launcher for Minecraft: Java Edition. It is under active development and aims to bring game installation, Java runtime management, account management, and mod discovery into one place.

## CurseForge integration

CurseForge support is currently disabled while official API access is under review. The planned integration is limited to Minecraft mod search, project and file details, compatibility filters, and user-initiated installation where an author permits third-party distribution. Mod listings will credit their authors and link to the original CurseForge project. The launcher will not mirror or bundle CurseForge files.

## Repository status

This public repository currently contains project information only. The launcher source code and binaries have not been published here.

Questions about the project can be opened as a GitHub issue.
